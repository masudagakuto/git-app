================================
Windowsクイックスタートガイド
================================

【必須】以下をインストールしてください:

1. Ruby 2.6.5 以上
   https://rubyinstaller.org/downloads/
   → Ruby+Devkit 2.6.5 をダウンロード・インストール

2. Git for Windows
   https://git-scm.com/download/win
   → ダウンロード・インストール

3. MySQL 5.5.8 以上
   https://dev.mysql.com/downloads/mysql/
   → ダウンロード・インストール

4. Ollama
   https://ollama.ai/download/windows
   → ダウンロード・インストール済み

================================
セットアップ実行
================================

【管理者権限で実行】

方法1: バッチスクリプト (推奨)
  1. setup.bat を右クリック
  2. 「管理者として実行」をクリック
  3. 完了を待つ

方法2: PowerShell
  1. PowerShell を右クリック → 「管理者として実行」
  2. 以下を実行:
     Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  3. 以下を実行:
     .\setup.ps1

方法3: 手動セットアップ
  管理者権限でコマンドプロンプトで以下を実行:

  gem install bundler
  bundle install
  rails db:create
  rails db:migrate

================================
Railsアプリの起動
================================

【ターミナル1】Ollama起動
  ollama serve

【ターミナル2】Rails起動
  cd C:\path\to\git-app
  rails s

【ブラウザでアクセス】
  http://localhost:3000/cad_analyzer

「接続テスト」ボタンで Ollama接続を確認してください。

================================
トラブル対応
================================

Q: Ruby が見つからないエラー
A: Rubyをインストール後、PCを再起動してください

Q: Bundle install が失敗
A: 以下を実行:
   gem install bundler
   bundle install

Q: MySQL に接続できない
A: MySQL が起動しているか確認:
   mysql -u root -p
   (パスワードなしで Enter を押す)

Q: Ollama に接続できない
A: ollama serve が起動しているか確認
